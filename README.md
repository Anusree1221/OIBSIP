# OIBSIP
# 🌐 Data Analytics Internship @ Oasis Infobyte

Welcome to my internship project repository for the **Data Analytics Virtual Internship Program** offered by **Oasis Infobyte**. This repository includes the tasks I completed as part of the internship program, aimed at enhancing my data analytics and visualization skills.


## 📌 Internship Overview

This internship provided hands-on experience in key areas of data analytics including **Exploratory Data Analysis**, **Customer Segmentation**, and **Sentiment Analysis**. I used Python and popular data science libraries to draw insights from real-world datasets.


## ✅ Tasks Completed

### 🔍 Task 1: Exploratory Data Analysis (EDA) on Retail Sales Data

- Analyzed a retail sales dataset to understand business performance.
- Identified sales trends, top-performing products, regions, and customer behavior.
- Created visualizations to support data-driven decision-making.

**Tools & Techniques:**  
`Pandas`, `Matplotlib`, `Seaborn`, `Data Cleaning`, `Trend Analysis`


### 🧠 Task 2: Customer Segmentation Analysis

- Applied clustering techniques (like K-Means) to segment customers.
- Identified key customer groups based on purchasing behavior.
- Helped understand target customer profiles for better marketing strategies.

**Tools & Techniques:**  
`Pandas`, `Scikit-learn`, `K-Means Clustering`, `Elbow Method`, `Data Preprocessing`, `Visualization`


### 💬 Task 3: Sentiment Analysis

- Conducted sentiment analysis on textual data (e.g., product reviews or tweets).
- Classified sentiments as positive, negative, or neutral using NLP techniques.
- Visualized sentiment distribution and word frequency.

**Tools & Techniques:**  
`NLTK`, `TextBlob`, `Pandas`, `Matplotlib`, `WordCloud`, `Text Preprocessing`


## 🛠️ Technologies Used

- **Programming Language:** Python  
- **Libraries & Tools:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, NLTK, TextBlob, WordCloud  
- **IDE:** Jupyter Notebook / VS Code  
- **Version Control:** Git & GitHub



## 📈 Outcomes

- Gained practical experience in data exploration, visualization, and modeling.
- Strengthened understanding of customer behavior and natural language processing.
- Enhanced Python programming and analytical thinking.
